# Contributing

Thanks for helping improve YouTube Video Sorter.

## Development setup

1. Fork and clone the repository.
2. Install Node.js 20 or newer.
3. Run `npm ci` to install the development dependencies.
4. Run `npm run lint` before opening a pull request.
5. To try the extension, open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the repository directory.

## Pull requests

- Keep changes focused and describe the user-visible behavior they affect.
- Include steps to reproduce and screenshots for visible UI changes.
- Confirm the extension loads in Chrome and that `npm run lint` passes.

For larger changes, open an issue first to discuss the approach.
